Introduction générale

Dans le cadre de ma première année à l'École Supérieure de Technologie d'Oujda (filière Systèmes d'Information et Ingénierie de Données), j'ai effectué un stage d'initiation au sein de la société SECUREX à Agadir, un centre agréé de contrôle technique des véhicules.

Le but de ce stage est simple :

  • Découvrir le monde du travail et la vie d'une entreprise réelle ;
  • Comprendre comment l'entreprise organise son activité au quotidien ;
  • Étudier le site web de l'entreprise (SECUREX CONNECT) qui permet aux clients de prendre rendez-vous en ligne, et faire le lien avec ce que j'ai appris en cours (base de données, méthode Merise : MCD, MLD, MPD).

Ce rapport est organisé en quatre chapitres : le premier présente l'entreprise, le deuxième présente le site web, le troisième explique l'analyse et la conception de la base de données avec la méthode Merise, et le dernier présente les technologies utilisées.

1.2 Activité de l'entreprise

SECUREX est un centre de visite technique agréé installé dans le quartier industriel d'Agadir. Son métier principal est de vérifier que les véhicules respectent les normes de sécurité et de pollution imposées par la loi marocaine.

Au Maroc, chaque véhicule doit passer un contrôle technique périodique (la « visite technique »). Le centre SECUREX contrôle plusieurs types de véhicules :

  • Les voitures (véhicules légers) ;
  • Les motos et cyclomoteurs ;
  • Les camions (poids lourds) ;
  • Les véhicules utilitaires.

Pendant la visite, les agents contrôlent les points essentiels du véhicule : les freins, les feux (éclairage), les pneus, la pollution (émissions) et la carrosserie. Si le véhicule est en bon état, le client reçoit un certificat officiel. Sinon, il doit réparer les points défaillants puis revenir pour une contre-visite.

1.4 Déroulement d'un contrôle technique

Voici les étapes qu'un client suit quand il vient au centre :

  1. Prise de rendez-vous : le client réserve par téléphone, sur place, ou directement sur le site web ;
  2. Accueil : à son arrivée, le client présente les papiers du véhicule (carte grise) ;
  3. Contrôle : un agent visiteur contrôle le véhicule sur la ligne de contrôle (freins, feux, pneus, pollution, carrosserie) — environ 30 minutes ;
  4. Résultat : si tout est bon, le client paye et reçoit son certificat. Sinon, il doit réparer et revenir pour une contre-visite.

Chapitre 2 : Le site web SECUREX CONNECT

2.1 Pourquoi un site web ?

Avant, les clients devaient téléphoner ou se déplacer pour prendre un rendez-vous. Cela posait des problèmes : lignes occupées, files d'attente, oublis... Pour améliorer ce service, l'entreprise a mis en place un site web appelé SECUREX CONNECT.

Adresse du site : https://securex-agadir-fta3.vercel.app

Grâce à ce site, le client peut voir les tarifs, prendre rendez-vous en ligne en 2 minutes, et suivre ses rendez-vous depuis son espace personnel.

  • Gestion des tarifs et catégories : modifier les prix et les prestations ;
  • Gestion du contenu du site : modifier les textes de la page d'accueil ;
  • Gestion des utilisateurs : créer les comptes des employés (Super Admin, RDV, Réception).

3.2 Le MCD (Modèle Conceptuel de Données)

Le MCD représente les entités (les « choses » importantes : client, véhicule, rendez-vous...) et les associations entre elles, avec les cardinalités :

Figure 6 : MCD simplifié du site SECUREX CONNECT

Lecture simple : un CLIENT peut posséder plusieurs VÉHICULES (1,n) mais un véhicule appartient à un seul client (1,1). Un CLIENT peut réserver plusieurs RENDEZ-VOUS. Chaque rendez-vous concerne une seule PRESTATION, et chaque prestation appartient à une seule CATÉGORIE. À la fin, un rendez-vous peut donner un RÉSULTAT (0,1).

3.3 Le MLD (Modèle Logique de Données)

On transforme le MCD en tables. Les règles sont simples : chaque entité devient une table, et les associations (1,1)–(1,n) deviennent des clés étrangères (notées avec #).

CLIENT (idClient, nomClient, telephone, email, motDePasse)
VEHICULE (idVehicule, matricule, marque, modele, annee, #idClient)
CATEGORIE (idCategorie, nomCategorie, description)
PRESTATION (idPrestation, nomPrestation, prix, duree, #idCategorie)
RENDEZVOUS (idRdv, dateRdv, heureRdv, statut, #idClient, #idVehicule, #idPrestation)
RESULTAT (idResultat, resultatGlobal, freins, feux, pneus, pollution, carrosserie, #idRdv)

La clé primaire est soulignée. Le # indique une clé étrangère.

3.4 Le MPD (Modèle Physique de Données)

Le MPD est la traduction du MLD en langage SQL, pour créer réellement les tables dans la base de données (ici PostgreSQL). Voici un exemple simplifié :

CREATE TABLE CLIENT (
  idClient     SERIAL PRIMARY KEY,
  nomClient    VARCHAR(100) NOT NULL,
  telephone    VARCHAR(20)  UNIQUE NOT NULL,
  email        VARCHAR(100) UNIQUE NOT NULL,
  motDePasse   VARCHAR(255) NOT NULL
);

CREATE TABLE CATEGORIE (
  idCategorie  SERIAL PRIMARY KEY,
  nomCategorie VARCHAR(50) NOT NULL,
  description  TEXT
);

CREATE TABLE PRESTATION (
  idPrestation SERIAL PRIMARY KEY,
  nomPrestation VARCHAR(100) NOT NULL,
  prix         DECIMAL(8,2) NOT NULL,
  duree        INT,
  idCategorie  INT REFERENCES CATEGORIE(idCategorie)
);

CREATE TABLE VEHICULE (
  idVehicule   SERIAL PRIMARY KEY,
  matricule    VARCHAR(20) NOT NULL,
  marque       VARCHAR(50),
  modele       VARCHAR(50),
  annee        INT,
  idClient     INT REFERENCES CLIENT(idClient)
);

CREATE TABLE RENDEZVOUS (
  idRdv        SERIAL PRIMARY KEY,
  dateRdv      DATE NOT NULL,
  heureRdv     VARCHAR(5) NOT NULL,
  statut       VARCHAR(20) DEFAULT 'EN_ATTENTE',
  idClient     INT REFERENCES CLIENT(idClient),
  idVehicule   INT REFERENCES VEHICULE(idVehicule),
  idPrestation INT REFERENCES PRESTATION(idPrestation)
);

CREATE TABLE RESULTAT (
  idResultat    SERIAL PRIMARY KEY,
  resultatGlobal VARCHAR(10),
  freins        VARCHAR(10),
  feux          VARCHAR(10),
  pneus         VARCHAR(10),
  pollution     VARCHAR(10),
  carrosserie   VARCHAR(10),
  idRdv         INT UNIQUE REFERENCES RENDEZVOUS(idRdv)
);

Exemple de code simple

Voici un petit exemple de code qui va chercher la liste des catégories de véhicules dans la base de données pour les afficher sur la page des tarifs :

// On demande à la base de données la liste des catégories,
// avec leurs prestations, triées par ordre d'affichage
const categories = await db.category.findMany({
  orderBy: { sort: "asc" },
  include: { services: true },
});

Traduction en français simple : « donne-moi toutes les catégories, dans l'ordre, avec leurs prestations ». Le résultat est ensuite affiché dans la page Tarifs.
